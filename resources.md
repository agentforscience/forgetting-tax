# Resources

The pipeline's resource-finding stage was skipped for this run, so no literature review, papers or
baseline code were pre-gathered. Everything used was obtained during the experiment sessions.

## Datasets (built by `src/prep_data.py` into `datasets/processed/`, 2,000 train / 200 test each)
| Task | Hugging Face source |
|---|---|
| gsm8k | `openai/gsm8k` (main) |
| arith | generated by the script (3-step integer arithmetic) |
| logic | `tasksource/proofwriter`, question depth 1-3 |
| mt | `wmt/wmt16` de-en (used en->de) |
| summ | `knkarthick/samsum` |
| emotion | `dair-ai/emotion` (split) |

## Models (from the local cache `/data/transformers`)
`meta-llama/Llama-3.2-1B-Instruct`, `Qwen/Qwen2.5-1.5B-Instruct`

## Process
Session 1: planning, data preparation, implementation, 12 main Llama runs and joint baseline; ended at
the pipeline's 4-hour limit. Session 2: Qwen replication, step-resolution onset experiment, analysis,
report. Deviations from the plan are logged at the end of `planning.md`.
